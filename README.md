# Eyefuck - Omarchy Theme

A light-mode Omarchy theme with acid green (#ccff00) and yellow (#ffff00) palette, designed for the Viper/Venomancer (Dota 2) aesthetic.

## Colors
- **Accent**: `#ccff00` acid green
- **Selection**: `#ffff00` yellow
- **Muted**: `#ff00aa`
- **Background**: `#eaff2f`
- **Cyan**: `#00ffff`
- **Magenta**: `#ff00ff`
- **Red**: `#ff0055`
- **Green**: `#00ff00`
- **Blue**: `#0044ff`

## Installation
```bash
omarchy theme set eyefuck
```

## Warning
This theme uses maximum-saturation complementary colors designed to vibrate. May cause eye strain. Not responsible for ruined retinas.
